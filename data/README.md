# Dataset

This service uses the *public teaching* `insurance.csv` dataset from the existing Medical Insurance project.
Upstream: https://github.com/stedy/Machine-Learning-with-R-datasets/blob/master/insurance.csv

Download it yourself and save at `data/insurance.csv` before training. The CSV is not committed or included in the public ZIP because redistribution rights have not been established.

The dataset has six input fields (`age`, `sex`, `bmi`, `children`, `smoker`, `region`) and the `charges` label used **only during training**. This is **not** an actual claims-level dataset, and the $20,000 cutoff is illustrative rather than an underwriting rule.
